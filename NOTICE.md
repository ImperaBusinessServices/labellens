# Notices and attributions

LabelLens is a personal-use project.

## Meta Wearables Device Access Toolkit (MWDAT)
The iOS app is built against Meta's Wearables Device Access Toolkit and is
grounded on patterns from Meta's official sample apps (e.g. `CameraAccess`,
`DisplayAccess`, `CarMaintenanceDisplay`) in the
[facebook/meta-wearables-dat-ios](https://github.com/facebook/meta-wearables-dat-ios)
repository. Those samples informed the session/capture/display and registration
patterns used here.

## OpenGlasses
The project plan referenced the open-source **OpenGlasses** project (licensed

OpenGlasses source code has been copied into this repository. **If any
OpenGlasses code is adapted in future, its BUSL 1.1 license notice must be
